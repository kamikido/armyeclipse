# ARMY Eclipse — Экзаменационная система National Guard

**ARMY Eclipse** — клиентское веб-приложение для проверки знаний личного состава фракции **National Guard** в GTA 5 RP. Система включает учебный центр с базой уставов, панель инструктора с лекциями и генератором экзаменационных ключей, а также сам экзаменационный модуль с таймером, защитой от списывания и автоматическим подсчётом результатов.

Приложение работает **без сборки и сервера** — достаточно открыть `index.html` в браузере.

---

## Возможности

- 🎓 **Учебный центр** — база знаний (уставы, кодексы, законы), таблица баллов и критерии повышения по рангам.
- 🗝️ **Экзамены по ключу** — инструктор генерирует одноразовый ключ, кандидат вводит его и приступает к экзамену.
- 📚 **5 типов экзаменов** по рангам: `3 ➔ 4`, `4 ➔ 5`, `5 ➔ 6`, `10 ➔ 11`, `11 ➔ 12`.
- ⏱️ **Таймер** — 30 минут на экзамен, автозавершение при истечении времени.
- 🛡️ **Античит** — блокировка контекстного меню, копирования/вставки, PrintScreen и DevTools.
- 🧪 **Демо-режим** — 5 вопросов без ключа, с подсветкой правильных ответов.
- 📖 **Лекции инструктора** — готовые скрипты лекций с копированием объявлений «Начало»/«Окончание».
- 🌗 **Тёмная и светлая темы** — выбор сохраняется в `localStorage`.
- 📱 **Адаптивная вёрстка** — работает на десктопе и мобильных устройствах.

## Как это работает

### 1. Генерация ключа (инструктор)

Инструктор авторизуется в панели (`admin.html`), заполняет никнейм кандидата, тип экзамена и дату. Система формирует **base64-токен** с данными:

```json
{
  "nick": "Marcus DeHaus",
  "exam": "3-4",
  "date": "2026-08-02",
  "timestamp": 1754120000000,
  "expiresAt": 1754121800000,
  "issueId": "a1b2c3d4",
  "secret": "***"
}
```

Ключ выдаётся кандидату.

### 2. Ввод ключа (кандидат)

На странице тестирования кандидат вставляет ключ. Система проверяет:

- корректность секрета;
- полноту данных (ник, экзамен, дата, `issueId`);
- существование типа экзамена;
- совпадение даты с текущей (`ключ действует только в указанную дату`);
- срок действия (`expiresAt`);
- одноразовость (ключ нельзя использовать дважды в одном браузере).

### 3. Сдача экзамена

При успешной валидации запускается экзамен:

- вопросы и варианты ответов **перемешиваются**;
- на экзамен даётся **30 минут**;
- по истечении времени экзамен завершается автоматически;
- проходной порог — **80%** правильных ответов.

### 4. Результат

После завершения формируется карточка результата: статус «СДАЛ / НЕ СДАЛ», количество правильных ответов, дата и уникальный код результата. Попытка сохраняется в `localStorage` браузера.

## Демо-режим

Без ключа можно ознакомиться с вопросами экзамена:

1. Перейдите в **Учебный центр** → вкладка **Тестирование**.
2. В блоке «Демо-экзамен» выберите повышение.
3. Нажмите **ОТКРЫТЬ ДЕМО**.

Будет показано 5 вопросов, а после завершения — подсвечены правильные и неправильные ответы.

**Прямая ссылка:** `exam.html?demo=true&from=3&to=4`

## Панель инструктора

Доступна из **Учебного центра** по кнопке «Панель инструктора» (`admin.html`).

### Вход

- Логин и пароль проверяются на стороне клиента.

### Вкладка «Лекции»

- Готовые скрипты лекций по уставам.
- Кнопка **НАЧАЛО** — копирует в буфер объявление о начале лекции.
- Кнопка **ОКОНЧАНИЕ** — копирует объявление об окончании лекции.

### Вкладка «Экзамен»

- Форма генерации ключа: никнейм кандидата, тип экзамена, дата.
- Сгенерированный ключ копируется одной кнопкой.

---

## Защита от списывания

Во время реального экзамена (не демо) блокируются:

- контекстное меню (правый клик);
- `Ctrl+C / Ctrl+V / Ctrl+X / Ctrl+A / Ctrl+S / Ctrl+P / Ctrl+U`;
- `PrintScreen`;
- открытие DevTools (`F12`, `Ctrl+Shift+I/J/C`).

## Настройка и администрирование

Все настройки находятся в `assets/config.js`:

| Параметр                   | Описание                                          |
|----------------------------|---------------------------------------------------|
| `SECRET`                   | Секретный ключ, встраиваемый в экзаменационные токены |
| `ADMIN_LOGIN`              | Логин инструктора                                 |
| `ADMIN_PASSWORD_MD5`       | MD5-хэш пароля инструктора                        |
| `DEFAULT_PASS_RATE`        | Проходной порог по умолчанию (0.8 = 80%)          |
| `EXAM_DURATION_MS`         | Длительность экзамена в миллисекундах             |
| `EXAMS`                    | Конфигурация типов экзаменов (вопросы, порог)     |

> ⚠️ **Внимание:** перед публикацией проекта **обязательно смените** секрет, логин и пароль инструктора в `config.js`. Не указывайте реальные значения в открытом доступе.

### Изменение вопросов и лекций

- **Вопросы:** `assets/questions.js` — объект `ArmyExamQuestionsFallback`, сгруппирован по типам экзаменов (`"3-4"`, `"4-5"`, `"5-6"`, `"10-11"`, `"11-12"`).
- **Лекции:** `assets/lectures.js` — массив `ArmyExamLecturesFallback` с полями `id`, `title`, `subtitle`, `announcement`, `closingAnnouncement`, `goal`, `script`, `points`, `check`.
